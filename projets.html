Installation et configuration d'un serveur Active Directory

Février 2026

📋 Contexte

TP a l'école réalisation de la gestion de ses utilisateurs et postes de travail. Mission : déployer un domaine Active Directory .

🎯 Objectifs

  • Installation de Windows Server 2022
  • Configuration d'Active Directory Domain Services
  • Création d'unités organisationnelles (OU)
  • Mise en place de stratégies de groupe (GPO)
  • Intégration des postes clients au domaine

🛠️ Environnement technique

Windows Server 2022 Active Directory DNS GPO PowerShell

⚙️ Réalisations

  • Installation et configuration du rôle AD DS
  • Création de la structure d'OUs (Services, Utilisateurs, Ordinateurs)
  • Configuration de GPOs pour la sécurité des mots de passe
  • Installation et configuration du server 2022
  • Documentation complète de l'infrastructure

🚧 Difficultés rencontrées

Problème de réplication DNS entre les contrôleurs de domaine. Résolu en vérifiant la configuration des zones DNS et la connectivité réseau.

✅ Résultats

Domaine Active Directory opérationnel, utilisateurs créés et organisés, GPOs appliquées avec succès.

📚 Compétences mobilisées

Administration systèmes Windows Scripting PowerShell Gestion des identités Documentation technique
