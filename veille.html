8 Février 2026 Vulnérabilités

Faille critique dans OpenSSH : CVE-2026-XXXX

Source : CERT-FR, The Hacker News

Résumé :

Une vulnérabilité critique a été découverte dans OpenSSH versions 8.5 à 9.6, permettant potentiellement une exécution de code à distance. Cette faille affecte des millions de serveurs Linux dans le monde.

Analyse :

Cette découverte rappelle l'importance de maintenir les logiciels à jour, particulièrement les services exposés sur Internet comme SSH. Les administrateurs systèmes doivent appliquer les correctifs dès que possible et envisager des mesures temporaires comme la limitation des accès SSH par IP.

Impact pour un administrateur SISR :

  • Audit immédiat de tous les serveurs utilisant OpenSSH
  • Planification de la mise à jour vers la version corrigée
  • Renforcement temporaire avec des règles de pare-feu
  • Surveillance accrue des logs d'authentification

1 Février 2026 Ransomware

Nouvelle vague d'attaques LockBit 4.0 ciblant les PME

Source : Bleeping Computer, ANSSI

Résumé :

Le groupe de ransomware LockBit a lancé une nouvelle campagne ciblant spécifiquement les PME européennes avec une variante améliorée de leur malware. Les attaques exploitent principalement des RDP mal sécurisés et des VPNs obsolètes.

Analyse :

Les PME sont souvent des cibles faciles car elles n'ont pas toujours les moyens de mettre en place une cybersécurité robuste. Cette tendance souligne l'importance de bonnes pratiques de base : mots de passe forts, authentification multi-facteurs, sauvegardes régulières et isolées.

Recommandations :

  • Désactiver RDP sur Internet ou utiliser un VPN
  • Implémenter l'authentification à deux facteurs (2FA)
  • Maintenir des sauvegardes offline (règle 3-2-1)
  • Former les utilisateurs à la détection de phishing
  • Segmenter le réseau pour limiter la propagation

25 Janvier 2026

ARP DNS spoofing

Source : ANSSI — cert.ssi.gouv.fr | CVE MITRE — cve.org | NVD NIST — nvd.nist.gov | RFC 826 (ARP) | RFC 4035 (DNSSEC) | The Hacker News — thehackernews.com | BleepingComputer — bleepingcomputer.com | Kali Linux Documentation — kali.org/docs

Résumé :

Cette étude de faille technologique a permis de démontrer concrètement comment deux vulnérabilités protocolaires anciennement connues — l'absence d'authentification ARP et l'absence de signature DNS — peuvent être combinées pour réaliser une attaque Man-in-the Middle redoutable.
